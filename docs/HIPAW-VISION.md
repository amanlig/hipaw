# HiPaw: project intentions

Recorded October 19, 2026. HiPaw is independent of aiNavLog.

## Purpose

A personal portal for memories of the owner and their two dogs, Levi and Rocky. Levi is living; Rocky has passed away. Memories may feature either dog or both.

The longer-term intention includes both recreating past moments and imagining new experiences using past memories as source material. These generated projections should be distinct from original records.

## This milestone

Establish a welcoming home page and record the vision. The root `index.html` and `home.css` form a standalone static page. Open `index.html` directly in a browser; no build or installation is needed. Existing React Photo Gallery source, examples, and build configuration remain available separately.

The page uses initials and a decorative paw illustration, not invented likenesses of Levi or Rocky. It contains no uploads, accounts, storage, generation, analytics, or external assets. It does not expose any personal photos. This commit does not configure hosting.

## Future direction — not implemented

- Separate dog profiles with shared memories linked to both when appropriate.
- Photos, videos, voice notes, stories, and contextual details.
- A memory timeline and browsing experience.
- Recreate: generated interpretations of selected past moments.
- Imagine: new scenes grounded in selected memories and each dog's characteristics.
- Preserve original media and link generated creations to their sources.
- Make revisiting or generating memories of Rocky an intentional user choice.

A private single-user portal and image-plus-story generation were suggested as a starting point. Platform, storage, authentication, generation provider, privacy controls, and implementation scope still need decisions. The current static home page is not an authenticated private portal.

## Where to resume

Choose the first memory-saving flow, decide where originals should be stored, and provide approved photos of Levi and Rocky if desired. Establish privacy and access before enabling personal uploads. Video generation can be considered later.
